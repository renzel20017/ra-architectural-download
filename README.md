# RA Architectural — download

Tools for Autodesk Revit, by RA Signum. **Beta: you need the beta key Renz gave you.**

## Download

**[RA-Architectural-Setup-1.2.1.exe](https://github.com/renzel20017/ra-architectural-download/releases/latest/download/RA-Architectural-Setup-1.2.1.exe)** (about 5 MB) — or see [all releases](https://github.com/renzel20017/ra-architectural-download/releases).

## Install

1. Close Revit if you can.
2. Double-click the file. If Windows says *"Windows protected your PC"*, click **More info → Run anyway** (the setup is not signed yet).
3. Choose **English** or **日本語**. The tools use the same language.
4. Follow the pages. Type your beta key (`RA-XXXX-XXXX-XXXX`) when asked.
5. Start Revit and open the **RA Architectural** tab. The **Manual** button explains everything.

No administrator rights are needed. Revit 2023 or later, with pyRevit (Setup offers to install it).

## インストール方法

1. できれば Revit を閉じてください。
2. ファイルをダブルクリックします。「Windows によって PC が保護されました」と表示されたら、**詳細情報 → 実行** をクリックします (セットアップはまだ署名されていません)。
3. **日本語** を選びます。ツールも同じ言語になります。
4. 画面に従って進み、ベータ キー (`RA-XXXX-XXXX-XXXX`) を入力します。
5. Revit を起動し、**RA Architectural** タブを開きます。使い方は **マニュアル** ボタンで確認できます。

管理者権限は不要です。Revit 2023 以降と pyRevit が必要です (セットアップがインストールを提案します)。
